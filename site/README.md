# Portfolio site

Personal portfolio built on [RyanFitzgerald/devportfolio](https://github.com/RyanFitzgerald/devportfolio) (Astro + Tailwind).

**Live:** https://mkm-007.github.io/MKM/

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Content lives in `src/config.ts`. Deployed via GitHub Actions on push to `main`.
